# Python Learning

Python code, lesson examples and solved exercises based on the **Python Fundamental 1 and 2** courses from IFSC (Instituto Federal de Santa Catarina), organized by topic. Code comments and exercise statements are written in Portuguese.

## Topics

| Folder | Topic |
|---|---|
| `01_introducao` | Introduction to programming and the Python language |
| `02_dados_operadores` | Data types and operators |
| `03_variaveis_entrada` | Variables and user interaction |
| `04_condicionais` | Conditional structures |
| `05_logicas_bit_a_bit` | Logical and bitwise operations |
| `06_listas` | Lists |
| `07_repeticao` | Loops |
| `08_matrizes` | Matrices |

Each folder contains `exemploXX.py` files (lesson examples) and `exercicioXX.py` files (commented solutions).

## Running in VS Code

1. Install **Python 3.10+** (required for `match-case`):
   - **Windows:** download from [python.org](https://www.python.org/downloads/) and check *"Add python.exe to PATH"*.
   - **Linux:** `sudo apt install python3` (or your distro's package manager).
   - **macOS:** `brew install python` or the installer from python.org.
2. Verify the installation: `python --version` (or `python3 --version`).
3. Open the repository folder in VS Code and accept the recommended extensions (Python, Python Debugger and Code Runner).
4. Run a `.py` file with the **Play** button, **Ctrl+F5**, or **F5** to debug.

> Programs that use `input()` run in the integrated terminal so you can type values.

## Terminal alternative

```bash
python 04_condicionais/exercicio01.py
```
